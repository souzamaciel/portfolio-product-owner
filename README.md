# Portfólio — Lucas Maciel

Portfólio responsivo desenvolvido a partir do layout no Figma.

## Executar localmente

Na pasta do projeto, rode:

```bash
python3 -m http.server 4173
```

Depois, acesse `http://localhost:4173`.

## Páginas

- `index.html`: página principal com apresentação, projetos e stack.
- `analise-laboratorial-inteligente.html`: case sobre análise de exames com IA.
- `plataforma-gestao-clinica.html`: case sobre a evolução de um SaaS para clínicas.
- `copiloto-prontuario.html`: case sobre automação do prontuário com IA.
- `assistente-protocolos-clinicos.html`: case sobre geração assistida de protocolos clínicos.

O projeto usa HTML, CSS e JavaScript puros, sem etapa de build.
